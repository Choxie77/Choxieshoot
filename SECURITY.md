# Security & Privacy Policy

## Privacy First
Choxieshoot is architected as a 100% offline, local utility:
- **No Network Requests**: Choxieshoot contains no network code, telemetry, analytics, or external API endpoints.
- **Local OCR**: All Optical Character Recognition is computed on-device using Apple's Vision framework.
- **Local Storage**: All screenshots, recordings, and configurations reside exclusively on your local machine.

## Reporting a Vulnerability
If you discover a security vulnerability or unintended behavior, please report it responsibly by opening a GitHub issue or submitting a security advisory through the repository's Security tab.
